🏎️ Car Rental System (Core Java Project)

The Car Rental System is a console-based Java application designed to simulate a real-world car rental service using only core Java concepts (no frameworks). It provides key functionalities such as adding and listing cars, registering customers, renting and returning vehicles, and generating rental summaries — all managed through a simple text-based menu. The project is built with a strong object-oriented programming (OOP) structure, featuring classes like Car, Customer, Rental, and a central CarRentalService that handles all business logic. It demonstrates practical application of core and advanced Java topics including variables, data types, control statements, loops, constructors, methods, classes and objects, encapsulation, inheritance, polymorphism, abstraction, interfaces, enums, generics, comparators, StringBuilder, autoboxing/unboxing, abstract classes, and composition.
The project also integrates concepts such as method overloading and overriding, object relationships, and clean code design principles, making it a comprehensive example of applying OOP principles to a real-world scenario.
